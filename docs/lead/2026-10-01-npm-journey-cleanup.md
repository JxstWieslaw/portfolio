- **D2 CI red on `main` is fixed first, in isolation.** Root cause: the merge commit f3244a8 (main into chore/next-15-5-24) mis-resolved `pnpm-lock.yaml`; every job dies at install with `ERR_PNPM_LOCKFILE_MISSING_DEPENDENCY @rolldown/binding-android-arm-eabi@1.2.12`. Fix: regenerate the lockfile (PR #16). Done before the npm move so every other PR's CI can install, and so a failure in the migration PR is the migration's own.
- **D3 pnpm → npm workspaces, Turborepo kept.** Why: pnpm's virtual store (`node_modules/.pnpm/<pkg>@<ver>_<hash>/…`) pushes paths past Windows MAX_PATH in agent worktrees, which broke vitest twice today; pnpm 9 runs lifecycle scripts by default and its reinstall prompt no-ops under a null stdin; npm's flat tree has none of these, is what Vercel, Render and Docker expect by default, and the repo has one maintainer. Costs accepted: slower installs, bigger node_modules, the `workspace:` protocol replaced by `*`, the API Dockerfile rebuilt around `turbo prune --docker` + `npm ci --omit=dev`. Logged as a devops task with every CI gate kept.
- **D4 Experience progression without a contract change.** The Experience contract has one title per entry and the API seeds those rows into Postgres (`experiences` table); extending the contract would mean an expand/contract migration for a presentation concern. Instead: one entry per role (two per company), and the Timeline groups entries by company at render time and shows the role ladder. Dates from Wieslaw's message, month precision: Data Age Senior Software Engineer 2025-01 → 2026-06, Tech Lead 2026-07 → now; Rapidev Labs Senior Software Engineer 2024-01 → 2026-07, Team Lead 2026-08 → now.
- **D5 "6+ years" returns.** The reconciliation rejected the export's `6+ years` as unverified copy; Wieslaw states it as fact on 2026-10-01, so the KPI moves from 5+ to 6+ and the Hero comment records the owner confirmation.
